# Security Policy

Please report vulnerabilities privately to **security@samt.qa**. Include steps to
reproduce and, if possible, a proof of concept. You will receive an
acknowledgement within 3 business days.

Please do not open public GitHub issues for security reports.

## Scope

- Signature verification of incoming webhooks
- Handling of API credentials and secrets
- Any path by which a payment could be marked paid without SkipCash confirming it
